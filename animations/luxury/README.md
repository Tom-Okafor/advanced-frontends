# LUXURY

This utilizes some of GSAP's methods like the play and reverse method and also the paused animation property to enable the implementation of pausing the animation, playing it on mouse enter and reversing the animation on mouse leave.

The animation in this sample animates a circular container to rectangular shape on hover while also revealing the full text that was cut off in its circular state. The container animates back to its original circular form on the mouse leave event.

### Technologies used

- GSAP
- HTML 5
- CSS 3
- JavaScript
